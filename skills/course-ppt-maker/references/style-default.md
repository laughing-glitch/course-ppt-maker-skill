# 默认风格

适合讲课投屏：底色柔和不刺眼，黑色通栏让每页一眼看出是同一套，黄绿色只用来突出重点。

| 项目 | 规定 |
|---|---|
| 画幅 | 16:9 横版（Codex 画出来约 1672×941，投屏够用） |
| 底色 | 暖米白 #F4EDD8 |
| 主色 | 纯黑 #111111 |
| 强调色 | 黄绿 #84CC16，只用在重点词、小标签、细线和图标点缀 |
| 插画 | 精致矢量线稿，黑色线条为主，少量黄绿；不要手绘涂鸦、渐变、阴影、彩色 emoji |
| 顶部通栏 | 占画面高度约 12%，纯黑，贴满左、右、上三边；左侧黄绿大字写「第 X 课 · 本课短标题」，右侧灰字写课程名 |
| 标题 | 主标题约占画面高度 10%，黑色加粗，左上或居中 |
| 正文 | 大字，坐在教室后排也能看清 |
| 底部 | 一条黄绿细线，左下灰色页码 |
| 封面 | 不要通栏也可以；左侧超大标题，右侧一幅和主题相关的线稿主图，左下署名和日期 |

## 换风格

用户给了参考截图，或者想换颜色时：

1. 看参考图，写出底色、主色、强调色（色值）、插画类型、通栏和页码的位置。
2. 把这些写成新的「公共风格段落」，替换提示词模板里的对应内容。
3. 先用新风格出 3 页样品给用户看，确认后再批量。

不要直接复刻别人的品牌标识、Logo 和署名。

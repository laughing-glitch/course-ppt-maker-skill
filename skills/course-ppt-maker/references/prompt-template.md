# 提示词模板

每页提示词 = 公共风格段落（每页完全一样）+ 本页内容 + 页码。`02-提示词.md` 里每页之间用 `----` 分隔，开头写「第N张 - 页面名」。

## 公共风格段落（默认风格）

把尖括号里的内容换成本课信息，其他字不要改。换了风格就按 `style-default.md` 重写这一段。

```text
【文字渲染规则】仅渲染反引号指定文字，逐字照写，每段只出现一次，不添加其他字。
16:9横版2K，专业杂志编辑排版，暖米白 #F4EDD8，纯黑 #111111 与黄绿 #84CC16。
精致矢量线稿，不要手绘涂鸦、渐变、阴影和彩色emoji。图文共同讲清这一页，不得退化成纯文字海报。
顶部12%纯黑通栏紧贴左右上三边，整条从左到右完全纯黑，上方和左右都不留米白边；左侧黄绿大字 `<第X课 · 本课短标题>`，右侧灰字 `<课程名>` 直接写在纯黑底上，灰字背后不能有任何色块。
主标题占画面高度约10%，正文大字以投屏能读为准，内容区不出现占位字和重复口号，不出现任何英文字母装饰；图标、插画、缩略图和屏幕内部不写任何文字、字母或数字，只画色块和线条。
底部黄绿细线，左下仅灰色页码。普通页不要署名和日期。
```

## 本页内容

```text
主标题与正文：`<标题>`；`<正文第一段>`；`<正文第二段>`。
版式：<主标题放哪；正文怎么排，比如三张横向卡片、左文右图；每张卡片上有什么线稿；哪几个词用黄绿突出>。
页码：`<两位页码>`。
```

## 封面额外加一句

```text
封面指定署名 `<署名>`，日期 `<日期>`，放在左下。
```

## 完整示例

```text
第3张 - 用AI做PPT一共三步

<公共风格段落>

主标题与正文：`用 AI 做 PPT，一共三步`；`第一步：让 AI 把每一页画出来`；`第二步：转成能改字的 PPT`；`第三步：检查错字和字体`。
版式：主标题左上。下方三张等宽横向卡片，从左到右用细箭头连接；每张卡片顶部一个线稿图标，依次是画笔、转换箭头、放大镜；卡片里的「第一步」「第二步」「第三步」用黄绿底小标签。
页码：`03`。
```

## 写提示词的要点

- 上屏的每个字都放进反引号，没放进去的字不会出现在图上。
- 一页文字太多时，AI 容易写错字，宁可拆页。
- 写清楚哪些词要黄绿突出，不写 AI 会随意上色。
- 版式描述越具体，样品越接近你想要的；含糊的描述会让每页风格飘。
